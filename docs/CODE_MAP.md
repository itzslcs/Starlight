- [FabricItem.java](../fabric/src/main/java/dev/kestrel/fabric/FabricItem.java): Reusable ItemRef view (one per slot, re-pointed each call; no allocation per frame).
- [FabricPlatform.java](../fabric/src/main/java/dev/kestrel/fabric/FabricPlatform.java): Platform for Fabric targets.
- [KestrelFabric.java](../fabric/src/main/java/dev/kestrel/fabric/KestrelFabric.java): Entrypoint + the static bridge the mixins call (keeps mixin bodies one line).
- [KestrelMixinPlugin.java](../fabric/src/main/java/dev/kestrel/fabric/KestrelMixinPlugin.java): Gate for kestrel.optional.mixins.json: skips a feature mixin when a mod that does the same job is loaded, or when the user lists it in -Dkestrel.mixins.disab...
- [KestrelScreen.java](../fabric/src/main/java/dev/kestrel/fabric/KestrelScreen.java): Vanilla Screen hosting core's GuiRoot; input and rendering are forwarded in GUI units.

## legacy · `dev.kestrel.forge.mixin`

- [GuiPlayerTabOverlayMixin.java](../legacy/src/main/java/dev/kestrel/forge/mixin/GuiPlayerTabOverlayMixin.java): Plugin name decorations in the 1.8.9 tab list.
- [ItemRendererMixin.java](../legacy/src/main/java/dev/kestrel/forge/mixin/ItemRendererMixin.java): Low fire: renderFireInFirstPerson's vertical offset (-0.3) and alpha (0.9).
- [MinecraftMixin.java](../legacy/src/main/java/dev/kestrel/forge/mixin/MinecraftMixin.java)
- [RenderMixin.java](../legacy/src/main/java/dev/kestrel/forge/mixin/RenderMixin.java): Plugin name decorations on 1.8.9 nametags.
- [RendererLivingEntityMixin.java](../legacy/src/main/java/dev/kestrel/forge/mixin/RendererLivingEntityMixin.java): Hit colour (the four puts of the hurt tint: 1, 0, 0, 0.3) and show-own-nametag.
